We started by using the existing chunk embedding cache from the multi-model agentic forest run to probe whether simple embedding contrast directions could recover feature-discovery signals. The core aggregation step is patient-level: retained text chunk embeddings are averaged within each patient, normalized, optionally residualized against configured structured columns, and then contrasted across patient groups. We first examined treatment and outcome marginal directions, retrieving the chunks most aligned with each direction, then also inspected the negative tails because the least-aligned chunks can be just as informative as the most-aligned chunks.

The early experiments were useful but also exposed a limitation. In the synthetic data, patient age is the true confounder, yet the positive treatment-vs-control tail did not clearly surface age. Looking at the negative tails helped clarify that scalar or monotone signals may appear as an opposition between tails rather than as an obvious high-similarity positive cluster. That led us to treat both tails as first-class evidence for treatment, outcome, and the derived confounder direction instead of only showing the most similar chunks.

We then considered effect-modifier discovery without assuming a nuisance model had been trained. The implemented no-nuisance effect-modifier construct is a raw 2x2 treatment/outcome interaction in embedding space, computed as the treated outcome contrast minus the untreated outcome contrast, then residualized against the marginal treatment and outcome directions. This produces a residualized_treatment_outcome_interaction vector intended to highlight text variation tied to heterogeneity beyond the main treatment and outcome associations. When R-style nuisance targets are available, the existing R-pseudo-target and orthogonal R-score embedding contrasts are still included as complementary nuisance-model-based evidence, but the residualized interaction path no longer depends on them.

The code now makes these ideas available in the multi-model agentic forest path and oracle script. Embedding contrast evidence includes positive and negative local chunk tails for treatment, outcome, confounder_vector, and residualized_treatment_outcome_interaction, plus the existing nuisance-based contrasts when applicable. We also added an external embedding cache builder so a separate corpus, such as PubMed abstracts, can be embedded with the same model and used for background retrieval against the derived contrast vectors. External chunks are treated as naming and interpretation support, not as data that changes the study-cohort contrast directions.
